## Project Purpose

A beginner Rust "Hello World" program (crate `hello_world`) that also serves as a sandbox for learning GitHub collaboration workflows. `docs/github-workflows.md` describes the fork-and-pull-request model this repo is used to practise:

- Upstream repository: `https://github.com/data-probe-1/test-repo` (owner/maintainer `data-probe-1`).
- Contributor `rohingosling` has no write access to upstream. They work through a fork (`rohingosling/test-repo`), using feature branches and pull requests.

Keep the code simple and well commented for beginners. The point of the repo is teaching, not features.

## Commands

```bash
cargo build          # Build
cargo run            # Build and run (prints "Hello World!")
cargo test           # Run tests (none exist yet)
cargo test <name>    # Run a single test by name filter
cargo clippy         # Lint
cargo fmt --check    # Format check. Note: rustfmt's defaults conflict with the house style below. Don't run `cargo fmt` without being asked.
```

## Code Style

Follow the existing style in `src/main.rs`, which uses the user's global coding standards rather than rustfmt defaults:

- Allman braces, spaces inside parentheses (`println!( "..." )`), and columnar alignment (see `Cargo.toml`).
- A file header block (Project, Version, Date, Author, Description, TODO) and a function header block (Function, Description, Arguments, Returns). Both are bordered with `//---` rules.
- Version `1.0.0` appears in both `Cargo.toml` and the `src/main.rs` header. Keep them in sync.
